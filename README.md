# 🏫 Sistema de Control Escolar - Backend API

Una API RESTful robusta construida con **Node.js, Express y PostgreSQL** para la gestión administrativa y académica de una escuela primaria.

El sistema maneja roles de usuario (Admin, Docente, Tutor), inscripciones, calificaciones, notificaciones automáticas y un flujo seguro de activación de cuentas vía correo electrónico.

## 🚀 Tecnologías

* **Runtime:** Node.js
* **Framework:** Express.js
* **Base de Datos:** PostgreSQL
* **ORM:** Sequelize
* **Seguridad:** JWT (JSON Web Tokens) & Bcryptjs
* **Emails:** Nodemailer
